# BORDEMAR WEB

Proyecto web oficial de Servicios Marítimos Bordemar SPA.

## Tecnología

- React
- Vite
- TypeScript
- CSS

## Abrir en VS Code

1. Descomprime la carpeta.
2. Abre VS Code.
3. Ve a `Archivo > Abrir carpeta`.
4. Selecciona `BORDEMAR_WEB_V0`.

## Instalar dependencias

Abre la terminal integrada de VS Code:

```bash
npm install
```

## Ejecutar en desarrollo

```bash
npm run dev
```

Vite mostrará una dirección similar a:

```text
http://localhost:5173/
```

Abre esa dirección en Chrome o Edge.
